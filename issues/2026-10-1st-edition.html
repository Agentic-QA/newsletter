New check management, token consumption on the Usage dashboard, and a new home for the Connect app.

Dear Agentic QA users,

Here is a roundup of our latest features and highlights. We have made organizing checks much easier, added more transparency to token consumption data for our on-prem users, and made it simpler to get started with the Agentic QA Connect app.

✨ What’s New

Improved Check Management

Checks now live in a hierarchical Check Repository organized by product. The scope of a test session can be defined either by checks selected directly from the Repository or by a reusable Test Set. Every check is stored once and can be used in as many Test Sets and sessions as you need, so an update made in one place flows everywhere. Existing Check Suites are migrated automatically. New this week: we added JSON export and import for checks for faster setup of new installations or projects.

Token Consumption on the Usage Dashboard

Installations that are not billed in Service Points can now switch the Usage dashboard to runtime and token consumption. See total and average tokens per session, toggle between Runtime and Tokens in the chart, and find a new Tokens column in the session table and in CSV/XLSX exports. This view can be activated by admins on the SOW usage page.

Our App for Local Testing Gets a New Home

The Connect app, which lets sessions run on your own machine with its browser, your MCP servers, and native Windows apps, now has a dedicated landing page at connect.testinator.ai with download links for Windows and macOS and a three-step setup guide. The new app also fetches fresh updates automatically, so you always run the latest version without reinstalling.

📣 New Case Study

Testing 3D games without SDK access

A global streaming platform offers cloud gaming, including a variety of casual games. Third parties submit the games, and each one must be verified before it is published. The platform provider wanted AI agents to perform autonomous testing, without SDK or codebase access, on released games to evaluate feasibility.
