# Newsletter assets

Static files referenced by newsletter issues.

| Folder | Use |
|---|---|
| `images/headers/` | Issue banner / hero images |
| `images/content/` | Inline article images, screenshots |
| `images/icons/` | Social and small UI icons |
| `logos/` | Brand logos |
| `css/` | Shared stylesheets |
| `fonts/` | Self-hosted web fonts |

## Conventions
- Names: lowercase, hyphenated, e.g. `2026-10-hero.png`
- Prefix issue-specific images with the issue date (`YYYY-MM-`)
- Email-safe formats: PNG, JPG, GIF; keep images under ~200 KB and max 1200px wide
